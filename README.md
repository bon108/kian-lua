# kian-lua ― 公文書起案用 LaTeX マクロ kian の LuaLaTeX 版

kian-lua は、秦誠一郎（Seiichiro HATA）氏が公開している公文書起案用 LaTeX マクロ
**kian**（<https://hata-o.jp/kian/>）を、LuaLaTeX（luatexja）向けに改編した派生物です。
訴状・準備書面・陳述書・証拠説明書など、日本の裁判所提出書面によく使う書式
（当事者欄、宛先、署名欄、公用文の見出し番号体系等）をマクロとして提供します。

## 必要環境

- **LuaLaTeX**（TeX Live 等に同梱。`luatexja` パッケージが必要）
- `tabularray`（証拠説明書テンプレートの表組みに使用。TeX Live 同梱）
- 和文フォント: **原ノ味明朝**（HaranoAjiMincho-Regular）
- （任意）IVS異体字を使う場合のみ: **IPAmj明朝**（入手方法は後述）

## コンパイル方法

### A. コマンドライン（ターミナル）

リポジトリのルートディレクトリで以下を実行:

```sh
latexmk -r latexmkrc-lua template-XXXX-lua.tex
```

例:
```sh
latexmk -r latexmkrc-lua template-sojo-lua.tex
```

中間ファイルの削除:
```sh
latexmk -r latexmkrc-lua -c template-sojo-lua.tex
```

> **注意**: `latexmkrc-lua` を `.latexmkrc` としてルートに置かないこと。
> 他の `.tex` ファイルまで意図せず LuaLaTeX で処理しようとして失敗することがあります。

### B. VS Code（LaTeX Workshop）

各テンプレートの先頭に `% !TEX recipe = LuaLaTeX (kian-lua)` を記述しておくと、
VS Code 上で開いてビルドするだけでレシピが自動選択されます。

## 異体字（IVS）の使い方

全テンプレートで `\usepackage{kian-ivs}` は**既定でコメントアウト**されています。
異体字を使用する場合は、先頭のコメントを外してパッケージを有効にしてください。

```tex
\usepackage{kian-lua}
% \usepackage{kian-ivs} %IVS 異体字（\ivs{文字}）  ← 先頭の % を外す
% \usepackage{kian-otf} %囲み文字拡張
% \usepackage{luatexja-ruby} %ルビ機能
```

氏名などにIVS異体字が必要な場合は `\ivs{文字}` マクロを使います。

```tex
% 「角」の突き出し字形（U+89D2 U+E0101）
\ivs{角󠄁}田　一郎
```

- `\ivs{}` 内の文字には IVS セレクタ（見えない制御文字）が付いています
- IPAmj明朝フォントで対象の字形が出力されます
- 異体字が不要な文字はそのまま通常フォント（原ノ味明朝）で組まれます

## ルビの使い方

全テンプレートで `\usepackage{luatexja-ruby}` は**既定でコメントアウト**されています。
`luatexja-ruby` は `luatexja` 同梱のため追加インストールは不要です。
先頭のコメントを外すと `\ruby{漢字}{かんじ}` でルビが振れます。

```tex
\usepackage{kian-lua}
% \usepackage{kian-ivs} %IVS 異体字（\ivs{文字}）
% \usepackage{kian-otf} %囲み文字拡張
% \usepackage{luatexja-ruby} %ルビ機能  ← 先頭の % を外す
```

## 主要コマンド一覧

`\Idcs`／`\Recs`／`\Sens` の複数形（`s` 付き）で統一しています
（`\Sen{…}`・単発 `\Rec` は現在未使用）。

| コマンド | 用途 | 例 |
|---|---|---|
| `\Tit{…}` | 書面の表題 | `\Tit{準備書面}` |
| `\Idcs{[o]{…}}` | 事件番号・当事者（統合1ブロック） | `\Idcs{[o]{R８(　)　　:【事件名】\\原告:【氏/名】:\\被告:【氏/名】}}` |
| `\Recs{[n]{…}}` | 宛先（裁判所・照会先等） | `\Recs{[n]{:【裁判所名】【支部名】支部:御中}}` |
| `\Sens{[0.5]{…}}` | 差出人・署名・作成者（複数行可） | `\Sens{[0.5]{【原告被告】訴訟代理人/弁護士:【氏名】\\}}` |
| `\Dat{…}` | 作成日 | `\Dat{令和８年　　月　　日}` |
| `\SecZ{…}` | 番号なし見出し | `\SecZ{記}` |
| `\SecA{…}` | 第1階層見出し（第１、第２…） | `\SecA{請求の趣旨}` |
| `\SecB{…}` | 第2階層見出し（１、２…） | `\SecB{当事者}` |
| `\SecC{…}` | 第3階層見出し（⑴、⑵…） | `\SecC{事故の状況}` |
| `\Jus[4]{…}` | 項目名の字詰め揃え（訴状当事者欄） | `\Jus[4]{住　所}` |
| `\ivs{…}` | IVS異体字切替（IPAmj明朝、要パッケージ有効化） | `\ivs{角󠄁}` |

### `\Idcs`／`\Recs`／`\Sens` のデータ内の区切り記号

- `:`（コロン）… 1行内を最大3つの部分（肩書／本体／続き等）に区切る
- `/`（スラッシュ）… 氏と名の間の字送り区切り（例：`【氏】/【名】`）。表示上スラッシュ自体は出力されない
- `\\` … データ内で複数行に分ける
- `[n]`（`\Recs`）… 宛先を右寄せ表示するオプション
- `[0.5]`（`\Sens`）… 行間を詰めた署名欄表示のオプション

### `\Sens` に住所・電話・ＦＡＸを入れる（答弁書）

答弁書は最初の応訴書面なので、差出人欄に代理人の郵便番号・住所・電話・ＦＡＸを
記載する。`template-toben-lua.tex` では `\Sens` のデータ行を次の3種類で組んでいる。

| データ行 | 意味 |
|---|---|
| `A=郵便番号:住所１//住所２//住所３` | `〒` 付きの住所行。`/` は長すぎる場合のみ自動改行、`//` は必ず改行する区切り |
| `A=:任意のテキスト` | 郵便番号を空にすると `〒` を付けずに、住所欄の書式で任意の行を組める。電話・ＦＡＸ欄はこの方法で作る |
| `N=肩書:氏/名` | 肩書付きの署名者 |

```tex
\senderhlength{11}{}{}{}% {字下げ}{肩書幅}{肩書と名前の間}{名前幅}（空欄は現状維持）
\Sens{
  [0.5]{%
    A=【郵便番号】:【事務所住所】//【ビル名・階】//【事務所名】\\
    N=【原告被告】訴訟代理人/弁護士:【氏名】\\
    A=:　　　　　　　　　　電　話　【電話番号】\\
    A=:　　　　　　　　　　ＦＡＸ　【ＦＡＸ番号】\\
  }
}
```

- **電話・ＦＡＸに `T=` は使わない。** `T=` 型はラベルが英語の `TEL`／`FAX` に
  固定されるため、「電　話」「ＦＡＸ」と書きたい場合は `A=:` の任意テキスト行で組む。
- **電話・ＦＡＸ行の頭揃え**は行頭の全角空白で行う。個数は「`〒`＋郵便番号」の
  字数＋１字（郵便番号の後の空き）。郵便番号７桁（`〒`付きで９字）なら
  全角空白１０個で住所行の書き出し位置と一致する。
  郵便番号の桁数を変えたときは空白の数も増減させること。
- ＦＡＸ行を `//` で継続行にすると自動字下げが入って揃わないので、行を分ける。
- `\senderhlength{①}{②}{③}{④}` は ①字下げ ②肩書幅 ③肩書と名前の間隔 ④名前幅
  （全角字数、空欄は現状維持）。既定の１３字では住所行が版面からはみ出して
  overfull hbox 警告が出るため、答弁書では１１字に詰めている。
- 肩書は既定１０字。`【原告被告】訴訟代理人`（１３字）のままだと２行に
  折り返されるので、`原告`／`被告` へ置き換えて１０字に収める。
- 送達場所の届出をする場合は、事務所名の後に「（送達場所）」を付す。

#### ⚠️ `\Sens` の中で使ってはならないもの

| やってはいけないこと | 何が起きるか |
|---|---|
| 「＝」を含む記述（`\Hsp[=]{10}` のようなオプション付きマクロ等） | 「＝」がデータの区切り記号と解釈されコンパイルエラーになる |
| 行頭字下げに `\Hsp{n}` 等のマクロを使う | 住所欄の行幅計算（`kian-titl.sty` の `\kian@titl@personaddress@B`）が「幅に収まらない」と誤判定し、同じ行が二重に出力される |

字下げは全角空白を必要個数並べて行うこと。

## otf 特殊文字（丸数字・かな囲み文字等）

全テンプレートで `\usepackage{kian-otf}` は**既定でコメントアウト**されています。
先頭のコメントを外してパッケージを有効にすると、丸数字・括弧数字等の番号コマンドに加えて
丸ひらがな・丸片仮名・かな括弧・汎用囲み文字が使えます（Unicode範囲外・かな等は
フォント非依存の自前合成で組版されます）。

```tex
\usepackage{kian-lua}
% \usepackage{kian-ivs} %IVS 異体字（\ivs{文字}）
% \usepackage{kian-otf} %囲み文字拡張  ← 先頭の % を外す
% \usepackage{luatexja-ruby} %ルビ機能
```

### 番号コマンド

| コマンド | 例 | 範囲 |
|---|---|---|
| `\丸{n}` | `\丸{21}` → ㉑ | 0〜99（51以上は自前合成） |
| `\括弧{n}` | `\括弧{3}` → ⑶ | 0〜99（21以上は自前合成） |
| `\黒丸{n}` | `\黒丸{5}` → ❺ | 0〜99（21以上は自前合成） |
| `\角{n}` | `\角{7}` | 0〜99（常に自前合成） |
| `\丸漢{n}` | `\丸漢{3}` → ㊂ | 1〜10 |
| `\括弧漢{n}` | `\括弧漢{2}` → ㈡ | 1〜99（11以上は自前合成） |
| `\丸英{n}` / `\丸英小{n}` | `\丸英{3}` → Ⓒ | 1〜26 |
| `\大ローマ{n}` / `\小ローマ{n}` | `\大ローマ{4}` → Ⅳ | 1〜39（13以上は加算合成） |

各コマンドには英語名のエイリアス（`\OtfMaru`・`\OtfKakko`・`\OtfKuroMaru`・`\OtfKaku`・
`\OtfMaruKanji`・`\OtfKakkoKanji`・`\OtfMaruAlph`／`\OtfMarualph`・`\OtfRomanNum`／`\OtfromanNum`）
も用意されており、どちらを使っても同じです。

### かな系・汎用囲みコマンド

かな系4コマンドは番号（`\丸平{3}`）でも、かな1字そのもの（`\丸平{う}`）でも指定できます。

| コマンド | 例 | 範囲 |
|---|---|---|
| `\丸平{n/かな}` | `\丸平{3}`＝`\丸平{う}` → ◯うの字体 | 1〜48（あ〜ん、常に自前合成） |
| `\丸片{n/カナ}` | `\丸片{3}`＝`\丸片{ウ}` → ㋒ | 1〜48（ア〜ン、48のみ自前合成） |
| `\括弧平{n/かな}` | `\括弧平{1}`＝`\括弧平{あ}` → （あ） | 1〜48 |
| `\括弧片{n/カナ}` | `\括弧片{1}`＝`\括弧片{ア}` → （ア） | 1〜48 |
| `\丸囲[倍率]{文字}` | `\丸囲{甲}`、`\丸囲[.7]{國}` | 任意の1文字を◯で囲む（既定倍率.785） |
| `\括弧囲[倍率]{文字}` | `\括弧囲{注}` → （注） | 任意の文字を括弧で囲む（既定倍率1） |

囲み文字はいずれも全角1文字幅に収まるよう自動調整されます。範囲外の値を渡すと
コンパイル時にエラーになり、PDF上にも警告マーカーが出ます。

### チェックボックス

☑／☐（チェックボックス記号）は原ノ味明朝に収録されていないため使えません。

使ってください（`kian-otf` の有効化は不要です）。

## 見出し番号体系と注意点（`\SecZ`〜`\SecG`）

番号書式は `kian-lua/kian-sect.sty` 側で固定されており、本文を空スケルトンにしても崩れない。

| コマンド | 番号書式 |
|---|---|
| `\SecZ` | 番号なし |
| `\SecA` | 第１，第２，第３… |
| `\SecB` | １，２，３… |
| `\SecC` | ⑴，⑵，⑶… |
| `\SecD` | ア，イ，ウ… |
| `\SecE` | (ア)，(イ)，(ウ)… |
| `\SecF` | a，b，c… |
| `\SecG` | (a)，(b)，(c)… |

### ⚠️ 空タイトルの見出しを連続させない

`\SecA{}` のように**タイトルを空**にした見出しを、間に本文（実テキスト）を挟まずに連続させると、

1. `Package kian-sect Error: Bad section order from "X" to "Y"` でコンパイルが止まる
2. 仮にエラーだけ回避しても、見出し番号が１行に混線して表示が壊れる
   （例：5個の空見出しを連続させると「第３⑴」のような崩れた１行になる）

**タイトルが非空の見出し**（`\SecA{当事者}` など）は本文が無くても常に独立した正しい行で表示され、
この問題は起きない。

タイトルを空のまま起案の下書き（スケルトン）にしたい場合は、各見出しの直後に最小限の
プレースホルダー本文を入れること:

```tex
\SecA{}

【ここに記載】

\SecB{}

【ここに記載】
```

## 訴状のIT化（電子提出）対応

裁判のIT化により、電子提出する訴状は以下の形式になった:

- 表紙部分（表題「訴状」・当事者欄・提出先・訴訟物価額）は**不要**（当事者等はシステムのフォーム入力）
- **請求の趣旨と請求の原因は1個のファイル（1個のPDF）にまとめてよい**
- 章番号は連続させ、**第１＝請求の趣旨、第２＝請求の原因**とする
- 証拠方法・附属書類は記載しない（証拠は証拠説明書 `template-shoko-lua.tex` で提出）

### 使用テンプレートと流れ

```
起案                コンパイル              提出
─────────────────────────────────────────────────────
件名-sojo-it-lua.tex  →  件名-sojo-it-lua.pdf  → 請求の趣旨及び原因として提出
件名-shoko-lua.tex    →  件名-shoko-lua.pdf    → 証拠説明書として提出
```

### コンパイル手順（電子提出版）

```sh
latexmk -r latexmkrc-lua example-sojo-it-lua.tex
```

訴状は1個のPDFにまとまるので、あとは証拠説明書を別途コンパイルして提出する。

### IT化版の技術的ポイント

- **表紙系コマンド（`\Tit`/`\Dat`/`\Sen`/`\Idcs`/`\Recs`）・`\maketitle` は置かない**
- **`\SecA{請求の趣旨}`**（第１）・**`\SecA{請求の原因}`**（第２）で章番号を通す
- 請求の原因の下位項目は `\SecB`（１…）・`\SecC`（⑴…）で書く
- **証拠方法・附属書類は記載しない**（証拠は証拠説明書で提出）

### 従来型（表紙あり）との使い分け

## フォント入手方法

いずれも GPL の対象外（別ライセンス）のため、本配布物にはフォント自体を同梱していません。

### 本文用フォント：原ノ味明朝（必須）

全テンプレートで本文フォントとして **原ノ味明朝**（HaranoAjiMincho）を使用します。

- **TeX Live を使っている場合**: CTAN の `haranoaji` パッケージとして TeX Live に収録されており
  （`tlmgr info haranoaji` で確認可）、日本語組版一式を含むインストールでは通常追加作業不要です。
  見つからない場合は次でインストールできます（Windows の TeX Live でも同様）:
  ```sh
  tlmgr install haranoaji
  ```
- 単体配布: <https://github.com/trueroad/HaranoAjiFonts>
- ライセンス: **SIL Open Font License, Version 1.1**
  - Copyright (C) 2019-2025 Masamichi Hosoda / (C) 2014-2025 Adobe
  - 商用・非商用を問わず、OFLの条件に従う限り無償で利用・再配布・改変可

### IVS異体字用フォント：IPAmj明朝（任意）

IVS 異体字（`\ivs{文字}`）を使う場合のみ **IPAmj明朝**（`ipamjm.ttf`）が別途必要です。

- 配布元: 一般社団法人 文字情報技術促進協議会
  <https://moji.or.jp/mojikiban/font/>
- ライセンス: **IPAフォントライセンス**（IPA Font License）
  - 商用・非商用を問わず無償で利用・再配布可
  - ただし改変フォントの再配布時は名称変更が必要等、GPLとは別条件のため、
    フォント自体を再配布する場合は同ライセンス文面を別途確認すること
- インストール後、`kian-ivs.sty` から `IPAmjMincho` の名前で自動参照される
