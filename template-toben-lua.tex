%  異体字: \ivs{文字} で IPAmj 明朝字形に切り替え（例: \ivs{角󠄁}）
%  ※ \SecA{} 等の {} 内に % を書くとコメントになりエラーが出ます
%  見出し番号: \SecZ=番号なし \SecA=第１ \SecB=１ \SecC=⑴ \SecD=ア \SecE=(ア)
%  ※ 見出し（\SecA{} 等）は本文なしで連続させると番号表示が崩れるため、
%    各見出しの直後に【ここに記載】のプレースホルダー本文を入れています
%
%  準備書面テンプレート（template-junbi-lua.tex）をベースに、答弁書
%  （最初の応訴書面）で必要となる差出人（事務所）の郵便番号・住所・電話・ＦＡＸを
%  \Sens ブロックに追加したもの。書式は簡易裁判所の調停回答書に倣った。
%
%  \Sens 内の書き方（詳細は README.md の「\Sens に住所・電話・ＦＡＸを入れる（答弁書）」を参照）：
%    ・「A=郵便番号:住所１//住所２//住所３」で住所行（〒付き）。
%      「/」は長すぎる場合のみ自動改行、「//」は必ず改行する区切り。
%    ・「A=:文言１」のように郵便番号を空にすると〒を付けずに、任意のテキストを
%      住所欄の書式で表示できる。電話・ＦＡＸ欄はこの方法で作成している
%      （\sender の T= 型はラベルが英語「TEL」「FAX」固定になり、事務所の
%      書式「電　話」「ＦＡＸ」と合わないため使わない）。
%    ・「N=肩書:氏/名」で署名者の肩書付き氏名（従来どおり）。
%
%  ★ \Sens の中で使ってはならないもの（いずれもハマりどころ）
%    ・「＝」を含む記述（\Hsp[=]{10} のようなオプション付きマクロなど）
%      → 「＝」がデータの区切り記号と解釈されコンパイルエラーになる。
%    ・行頭を字下げするための \Hsp{n} 等のマクロ
%      → 住所欄の行幅計算（kian-titl.sty の \kian@titl@personaddress@B）が
%        「幅に収まらない」と誤判定し、同じ行が二重に出力される。
%        字下げは全角空白を必要個数並べて行うこと。
% ============================================================

\documentclass{ltjsarticle}

\Idcs{
  [o]{R８(　)　　:【事件名】\\原告:【氏/名】:\\被告:【氏/名】}
}

\Tit{答弁書}
\Dat{令和８年　　月　　日}
\Recs{
  [n]{:【裁判所名】【支部名】支部:御中}
}
%\senderhlength{18}{4}{2}{10}% \senderhlength{①}{②}{③}{④}
% ①左端からのインデント（開始位置）② （肩書幅）「弁護士」という肩書を配置するボックスの横幅です。③ （肩書と名前の間隔）「弁護士」と「名前」の間に空けるスペースの幅です。④（名前幅）「【氏名】」という名前を均等割り付け（配置）するボックスの横幅です。
% 差出人ブロック全体の字下げ幅（全角字数）。既定の１３字では住所行が版面から
% はみ出しoverfull hbox警告が出るため、１１字に詰めている。
\senderhlength{11}{}{}{}% {字下げ}{肩書幅}{肩書と名前の間}{名前幅}（空欄は現状維持）
\Sens{
  [0.5]{%
    % 送達場所の届出をする場合は事務所名の後に「（送達場所）」を付す。
    A=【郵便番号】:【事務所住所】//【ビル名・階】//【事務所名】\\
    % 【原告被告】のままだと肩書が１３字になり肩書欄（既定１０字）に収まらず
    % ２行に折り返されるが、「原告」「被告」に置き換えれば１０字となり１行に収まる。
    N=【原告被告】訴訟代理人/弁護士:【氏名】\\
    % 電話・ＦＡＸの行は、左端を住所行の書き出し位置に揃える。
    % 行頭に置く全角空白の数は「〒＋郵便番号」の字数＋１字（郵便番号の後の
    % 空き）。郵便番号７桁（〒付きで９字）なら１０個で住所行と一致する。
    % （郵便番号の桁数を変えたときは、この空白の数も合わせて増減させること。）
    % ※ ＦＡＸを「//」で継続行にすると自動字下げが入って揃わないため、行を分ける。
    A=:　　　　　　　　　　電　話　【電話番号】\\
    A=:　　　　　　　　　　ＦＡＸ　【ＦＡＸ番号】\\
  }
}
