%              または VS Code の「LuaLaTeX (kian-lua)」レシピ
%  プレースホルダー: 【...】を実際の内容に置き換えてください

%
%  裁判所のひな形に合わせた本テンプレート固有の体裁（他のテンプレートと異なる点）:
%   ・１行目は「裁判所名　事件番号」。当事者（原告・被告）欄・事件名は表示しない
%   ・あて先行（\Recs）は置かない。裁判所名は１行目に含める
%   ・標題「証拠説明書」は年月日行の【前】に置く（\maketitle の引数で順序を指定）
%   ・表の直前（又は直後）に、民訴法231条の2の電磁的記録に関する注記を
%     \shokonote で１行入れる
%  詳細は README-templates-lua.md の「証拠説明書の体裁」を参照。
%
%  表は longtblr（tabularray）なので証拠の数が多くても自動的に複数ページへ分割され、
%  各ページの先頭に見出し行（号証・標目・作成年月日・作成者・立証趣旨・備考）
%  が自動的に再表示されます（rowhead=1 の働き。手動でのページ調整は不要）。
% ============================================================

\usepackage{tabularray}              % 表組み拡張（tblr/longtblr）。複数ページ分割・見出し行の自動繰り返しも標準機能。
% longtblrはデフォルトで「表1:」等のキャプション番号や「Continued on next page」の

% ------------------------------------------------------------
% 証拠説明書用 行マクロ（１号証＝１行）
% 使い方: \shokorow{号証番号}{標目}{作成年月日}{作成者}{立証趣旨}{備考}
%   #1 号証番号   … 例: {甲001}。複数行にしたい場合は { }で囲んだ素の\\を使う
%                    （例: {甲001\\-1.2}。書き方の注意は下記コメント参照）
%                    （号証欄の中央揃えは列側の設定(Q[c,m])で自動処理するため、
%                      \hspace や \makebox を自分で書く必要はありません）
%   #2 標目       … 文書名等。複数行にする場合はセル内で \newline または
%                    { }で囲んだ素の\\を使う（どちらでも可。下記コメント参照）。
%                    原本・写しの別を記載する場合は、この標目欄の記載の【末尾】に
%                    付記する（例: {契約書（写し）}、{陳述書（原本）}）。
%                    原本/写しの専用欄は廃止しており、独立した引数はない。
%   #3 作成年月日  … 例: {令和８年　　月　　日}
%   #4 作成者
%   #5 立証趣旨
%   #6 備考       … 特になければ {} のままでよい
% ------------------------------------------------------------
% #1(号証番号)はQ[c,m,...]列（横縦とも中央揃え）だが、
% 行の高さが内容ちょうどに自動計算される場合、tabularrayは列指定のvalign=mだけでは
% 縦中央に揃えてくれず下揃えになる仕様のため、\SetCell{c,m}で毎セル明示している。
% ※セル内容側に\raiseboxで手動の縦位置補正を入れると、行の高さ（＝行の内容量）
%   によって最適な補正量が変わってしまい、行ごとに中央からずれる原因になる。
%   縦中央揃えは\SetCell{c,m}に一任し、セル内容側では補正しないこと。
% ※複数行を1セル内で改行するには\shortstack{...\\...}ではなく素の\\を使い、
%   さらに{ }で囲むこと（例: {甲001\\-1.2}）。
%   - \shortstackは内部で\vtopを使うため、tabularrayの縦中央揃え（valign=m）の
%     高さ計算（1行目の上端／最終行の下端を基準にする方式）と噛み合わず、
%     他の列（通常の段落）と比べて上寄りにずれてしまう。
%   - \newlineは内部で\\を呼ぶが、tabularrayのvalign=c（横中央）と組み合わせると
%     セル内容の展開時に\\が正しく展開できず「Undefined control sequence」に
%     なることがある。素の\\なら問題ないが、{ }で囲まないとtabularrayが
%     行区切り（改行部分でセルを分割）と誤認して表の行が増えてしまう。
% ※改行コマンドの使い分け（重要）：
%   - #1号証欄はマクロ本体側で\SetCell{c,m}{#1}のように{ }でくくり直しているため、
%     呼び出し側で{ }に囲んだ素の\\が保護され使える。
%   - #2標目欄も同様にマクロ本体側で{#2}とくくり直しているため、他の欄と同じく
%     { }で囲んだ素の\\が使える（例: {写真\\撮影日時：...}）。加えて#2は
%     Q[l,...]＝横は左揃え列のため \newline も問題なく使える（Q[c,...]の中央揃え
%     列で\newlineを使うと展開時に「Undefined control sequence」になる場合が
%     あるため、中央揃え列では\newlineではなく上記の素の\\を使うこと）。
%     どちらの書き方でも見た目・行数への影響はない。
\newcommand{\shokorow}[6]{%
  \SetCell{c,m}{#1} & {#2} & #3 & #4 & #5 & #6 \\%
}

% ------------------------------------------------------------
% 表の直前（又は直後）に置く注記用マクロ
% 使い方: \shokonote{※「標目」欄に原本・写しの記載が……}
%  ・裁判所のひな形に合わせ、必ず１行に収める。
%    まず \scriptsize（本文の70%）で組み、それでも \linewidth に収まらない場合だけ
%    \resizebox で行幅ちょうどまで縮小する（graphicx は kian-lua が読み込み済み）。
%    文言を書き換えても自動的に１行に収まるので、ポイントの手動調整は不要。
%  ・注記と表の間隔は \shokonotesep だけにする。通常の行送りグルーは
%    \nointerlineskip で打ち消しているので、\vspace を自分で足す必要はない。
%    上下対称に間隔を入れているため、表の【直前】に置いても【直後】に置いても
%    同じ間隔で配置される。
%  ・※ longtblr 側で presep=0pt, postsep=0pt を指定しておくこと。
%    tabularray の既定値（1.5\bigskipamount＝約18pt）が残ると表側の余白が勝つ。
%
%  【改ページ対策】号証が多くて表がページ末ぎりぎりで終わると、注記だけが
%  次ページの先頭に取り残される。これを防ぐため、注記を出す直前にページの
%  残り高さ（\pagegoal-\pagetotal）を測り、注記の高さに足りないときだけ
%  \enlargethispage でそのページを注記の分（約1.5行）だけ伸ばす。
%  TeXは「版面があふれる直前の改ページ位置」で切るので、あふれさえしなければ
%  表と注記の間で改ページされない。
%  ※ 表の直前にある改ページ位置（longtblr の postsep のグルー）自体は
%    消せない（縦モードには \unskip に当たるものが無く、\removelastskip は
%    グルーを打ち消すだけで節点を消さない）。上記のとおりページを伸ばして
%    「あふれさせない」ことで対処している。
%  ※ 注記を表の【前】に置いた場合、表がまるごと次ページへ送られる状況
%    （そのページに表が1行も入らない場合）では、tabularray 側が強制改ページ
%    するため注記が前ページ末尾に残ることがある。表の後ろに置く現行の配置では
%    この問題は起きない。
% ------------------------------------------------------------
\newcommand{\shokonotesep}{0.3\zw}% 注記と表との間隔（詰めたい／広げたい場合はここを変える）
\newlength{\shokonoteht}%   注記が占める高さ（上下の間隔込み）
\newlength{\shokonoterest}% ページの残り高さ
\newcommand{\shokonote}[1]{%
  \par
  \begingroup
    % １行に収める
    \setbox0=\hbox{\scriptsize #1}%
    \ifdim\wd0>\linewidth
      \setbox0=\hbox{\resizebox{\linewidth}{!}{\usebox0}}%
    \fi
    \setlength{\shokonoteht}{\ht0}%
    \addtolength{\shokonoteht}{\dp0}%
    \addtolength{\shokonoteht}{\shokonotesep}%
    \addtolength{\shokonoteht}{\shokonotesep}%
    % ページ残量が足りなければ、そのページだけ伸ばす（改ページ対策）
    \ifdim\pagegoal<\maxdimen
      \setlength{\shokonoterest}{\pagegoal}%
      \addtolength{\shokonoterest}{-\pagetotal}%
      \ifdim\shokonoterest<\shokonoteht
        % 伸ばすのは不足分だけ（残量が負＝既にあふれている場合にも対応する）
        \addtolength{\shokonoteht}{-\shokonoterest}%
        \enlargethispage{\shokonoteht}%
      \fi
    \fi
    \nobreak\vskip\shokonotesep
    \nointerlineskip
    \box0%             縦モードに直接置く（前後に行送りグルーが入らない）
    \nobreak\nointerlineskip
    \nobreak\vskip\shokonotesep
    \nobreak% 注記を表の前に置いた場合に、注記と表の間で切らせないため
  \endgroup
  \par
}

% １行目は「裁判所名　事件番号」。裁判所のひな形に合わせ、当事者（原告・被告）欄と
% 事件名は表示しない。
%   ・行頭の「C=」は行タイプの明示指定でコメント行（「部分1　部分2」の並び）になる。
%     これを付けないと「裁判所名」が肩書、「事件番号」が氏名と誤判定される。
%   ・\Idn（＝\idcodenumber）は事件番号を整形する公開マクロ。
%     \Idn{R８(ワ)１８４３} → 令和８年（ワ）第１８４３号
\Idcs{
  [o]{C=【裁判所名】【支部名】支部:\Idn{R８(　)　　}}
}

\Tit{証拠説明書１}
\Dat{令和８年　　月　　日}
% 証拠説明書にはあて先行を置かない（裁判所名は上の \Idcs の１行目に記載する）。
%\senderhlength{18}{4}{2}{10}% \senderhlength{①}{②}{③}{④}
% ①左端からのインデント（開始位置）② （肩書幅）「弁護士」という肩書を配置するボックスの横幅です。③ （肩書と名前の間隔）「弁護士」と「名前」の間に空けるスペースの幅です。④（名前幅）「【氏名】」という名前を均等割り付け（配置）するボックスの横幅です。

% 標題の配置: i=事件番号 t=標題 d=日付 s=差出人（+は0.25行分の間隔）
% あて先(r)は使わないので指定しない。標題「証拠説明書」は年月日行の前に置く。
\maketitle[i+++t+++d++s]

\vspace{2\zw}

\begingroup
\renewcommand{\baselinestretch}{0.7}\selectfont%   セル内の複数行（\newlineや\\）の行間を調整
% 列幅の単位はすべて \zw（全角文字１文字分）。
% 全列を明示的に Q[...,m,wd=...] にしていること：bare の m{幅} は tabularray では
% 上揃え（array版のmとは異なる）になり、縦中央揃えが効かないため使わないこと。
% 現行の各列幅は下記のとおり（手動で微調整済み）。
%   第１列「号 証」　　… 3\zw+1pt   罫線に接するぶんの余白を見込んだ微調整
%   第２列「標　　目」　… 9\zw+4pt   旧・標目欄と旧・原本/写し欄を統合した幅
%   第３列「作成年月日」… 3\zw+20pt  "R8.8.7"のような半角文字混じりの日付が3\zwでは
%                                  収まりきらずoverfull hbox警告が出るための調整
%                                  （削って元の3\zwに戻すと再発する）
%   第４列「作成者」　　… 4\zw+1pt
%   第５列「立証趣旨」　… 9\zw+4pt
%   第６列「備 考」　　… 3\zw+3pt   通常は空欄なので、表全体の幅の帳尻合わせに使う列
% 合計は31\zw+33pt。表全体の幅が\linewidthを超えるとtabularrayが
% 「Table width is too small」と警告するため、どこかの列を広げたら別の列を削って
% 帳尻を合わせる必要がある（既定では備考欄で調整する。備考欄に記載する運用の場合は
% 他の余裕がある列で調整する）。
% 号証欄はQ[c,m,...]で中央揃え＋縦中央揃えを列側に指定しているため、
% \vcenterboxのような手製の縦中央揃えマクロは不要（tabularrayが自動で処理する）。
\begin{longtblr}[
  expand = \shokorow, % \shokorowマクロ内の&を展開してから表を組む（tabularrayの仕様）
  presep = 0pt, postsep = 0pt, % 表の上下の余白。tabularrayの既定は1.5\bigskipamount（約18pt）
                               % だが、\shokonote との間隔を\shokonoteだけで制御するため0にする。
]{
  colspec = {|Q[c,m,wd=\dimexpr3\zw+1pt\relax]|Q[l,m,wd=\dimexpr9\zw+4pt\relax]|Q[l,m,wd=\dimexpr3\zw+20pt\relax]|Q[l,m,wd=\dimexpr4\zw+1pt\relax]|Q[l,m,wd=\dimexpr9\zw+4pt\relax]|Q[l,m,wd=\dimexpr3\zw+3pt\relax]|},
  hlines, vlines,
  rowhead = 1,      % 先頭１行（見出し行）を全ページで繰り返す
  rowsep = 0pt,     % 行の上下余白。現行版(array版, \arraystretch=0.9)に合わせて調整済み
  row{1} = {abovesep=4pt, belowsep=4pt}, % 見出し行の上下余白
  column{1} = {leftsep=0pt, rightsep=0pt},
  column{6} = {leftsep=0pt, rightsep=0pt},
}
  % 見出し行の各セルにも \SetCell{c,m} を明示すること（\shokorowの#1と同じ理由）。
  % 複数行にする見出しは\shortstackではなく{ }で囲んだ素の\\を使うこと（理由は上記コメント参照）。
  \SetCell{c,m}号 証 & \SetCell{c,m}{標　　　目} & \SetCell{c,m}{作　成\\年月日} & \SetCell{c,m}作成者 & \SetCell{c,m}立証趣旨 & \SetCell{c,m}備 考 \\

  % ==========================================================
  % ここから証拠行。
  % 「\shokorow{...}{...}{...}{...}{...}{...}」１つが証拠１件（１行）分の単位です。
  %   ・行を増やす → このセットをまるごとコピーして下に貼り付ける
  %   ・行を減らす → このセットをまるごと削除する
  % セットの外側で & や \\ を直接書き足さないこと（列崩れの原因になります）。
  % hlines指定により行間の罫線は自動描画されるため、\hlineを書く必要はありません。
  % ==========================================================
  \shokorow
    {甲001}
    {【書証等の標目（例：陳述書、写真、契約書等）】\\【必要に応じ撮影日時・作成日・撮影者等を追記】（原本）}
    {R8.月.日}
    {【作成者】}
    {【立証趣旨】}
    {【備考】}
  % 号証番号を複数行にする場合の例（コメントアウト。必要なら使う）：
  %   {甲002\\-1}  … 号証欄を2行に
\end{longtblr}
\endgroup
