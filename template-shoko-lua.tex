% ------------------------------------------------------------
% 証拠説明書用 行マクロ（１号証＝１行）
% 使い方: \shokorow{号証番号}{標目}{原本/写し}{作成年月日}{作成者}{立証趣旨}{備考}
%   #1 号証番号   … 例: {甲１}。複数行にしたい場合は { }で囲んだ素の\\を使う
%                    （例: {甲１２\\の\\１・２}。書き方の注意は下記コメント参照）
%                    （号証欄の中央揃えは列側の設定(Q[c,m])で自動処理するため、
%                      \hspace や \makebox を自分で書く必要はありません）
%   #2 標目       … 文書名等。複数行にする場合はセル内で \newline または
%                    { }で囲んだ素の\\を使う（どちらでも可。下記コメント参照）
%   #3 原本/写し   … {原本} または {写し}
%                    （写し）のように括弧を付けると欄の幅(1\zw)に収まらず自動的に
%                    2行に折り返されるが、括弧が横書き用の向きのまま縦に並ぶと
%                    見た目が不自然になるため、括弧を90度回転して縦書きの括弧の
%                    向きに揃えて並べる：
%                      {\rotatebox{-90}{（}原本\\[-15pt]\rotatebox{-90}{）}}
%                    （末尾の\\[-15pt]は、回転後の閉じ括弧の直前だけ行間を詰める
%                      調整。\\と[-15pt]の間に空白・改行を入れないこと（入れると
%                      \\のオプション引数として認識されず、"[-15pt]"という文字列
%                      がそのまま印字されてしまう）。詳細は下記コメント参照）
%   #4 作成年月日  … 例: {令和８年　　月　　日}
%   #5 作成者
%   #6 立証趣旨
%   #7 備考       … 特になければ {} のままでよい
% ------------------------------------------------------------
% #1(号証番号)・#3(原本/写し)はQ[c,m,...]列（横縦とも中央揃え）だが、
% 行の高さが内容ちょうどに自動計算される場合、tabularrayは列指定のvalign=mだけでは
% 縦中央に揃えてくれず下揃えになる仕様のため、\SetCell{c,m}で毎セル明示している。
% ※セル内容側に\raiseboxで手動の縦位置補正を入れると、行の高さ（＝行の内容量）
%   によって最適な補正量が変わってしまい、行ごとに中央からずれる原因になる。
%   縦中央揃えは\SetCell{c,m}に一任し、セル内容側では補正しないこと。
% ※複数行を1セル内で改行するには\shortstack{...\\...}ではなく素の\\を使い、
%   さらに{ }で囲むこと（例: {甲１２\\の\\１・２}）。
%   - \shortstackは内部で\vtopを使うため、tabularrayの縦中央揃え（valign=m）の
%     高さ計算（1行目の上端／最終行の下端を基準にする方式）と噛み合わず、
%     他の列（通常の段落）と比べて上寄りにずれてしまう。
%   - \newlineは内部で\\を呼ぶが、tabularrayのvalign=c（横中央）と組み合わせると
%     セル内容の展開時に\\が正しく展開できず「Undefined control sequence」に
%     なることがある。素の\\なら問題ないが、{ }で囲まないとtabularrayが
%     行区切り（改行部分でセルを分割）と誤認して表の行が増えてしまう。
% ※改行コマンドの使い分け（重要）：
%   - #1号証欄・#3原本写し欄はマクロ本体側で\SetCell{c,m}{#1}のように{ }で
%     くくり直しているため、呼び出し側で{ }に囲んだ素の\\が保護され使える。
%   - #2標目欄も同様にマクロ本体側で{#2}とくくり直しているため、他の欄と同じく
%     { }で囲んだ素の\\が使える（例: {写真\\撮影日時：...}）。加えて#2は
%     Q[l,...]＝横は左揃え列のため \newline も問題なく使える（Q[c,...]の中央揃え
%     列で\newlineを使うと展開時に「Undefined control sequence」になる場合が
%     あるため、中央揃え列では\newlineではなく上記の素の\\を使うこと）。
%     どちらの書き方でも見た目・行数への影響はない。
%   - 回転文字（\rotatebox）を挟んで複数行にする場合、回転後の文字は見た目の高さが
%     変わり自動折返しでは行間が不揃いになるため、手動で\\[-15pt]のように負の
%     スキップを入れて詰める（例: 下記#3の（写し）の例）。
\newcommand{\shokorow}[7]{%
  \SetCell{c,m}{#1} & {#2} & \SetCell{c,m}{#3} & #4 & #5 & #6 & #7 \\%
}

\Idcs{
  [o]{R８(　)　　:【事件名】\\原告:【氏/名】:\\被告:【氏/名】}
}

\Dat{令和８年　　月　　日}
\Recs{

}

% ①左端からのインデント（開始位置）② （肩書幅）「弁護士」という肩書を配置するボックスの横幅です。③ （肩書と名前の間隔）「弁護士」と「名前」の間に空けるスペースの幅です。④（名前幅）「【氏名】」という名前を均等割り付け（配置）するボックスの横幅です。

  }

\renewcommand{\baselinestretch}{0.7}\selectfont%   セル内の複数行（\newlineや\\）の行間を調整
% 列幅の単位はすべて \zw（全角文字１文字分）。
% 全列を明示的に Q[...,m,wd=...] にしていること：bare の m{幅} は tabularray では
% 上揃え（array版のmとは異なる）になり、縦中央揃えが効かないため使わないこと。
% 「号証」欄は3\zw+5pt、「原本/写し」欄は1\zw+5ptとしているのは、罫線に接するぶんの
% 余白を確保するための微調整。「作成年月日」欄を3\zw+20ptとしているのは、
% "R8.8.7"のような半角文字混じりの日付が3\zwだけでは収まりきらずoverfull hbox警告が
% 出るための調整（削って元の3\zwに戻すと再発する）。その分、常に空欄の「備考」欄を
% 3\zw-4ptに削って表全体の幅を\linewidth内に収めている（表全体の幅が\linewidthを
% 超えるとtabularrayが「Table width is too small」と警告するため、どこかの列を
% 削って帳尻を合わせる必要がある。備考欄以外を使う場合は他の余裕がある列で調整する）。
% 号証欄・標目欄の間、標目欄・原本写し欄の間の余白調整：
%   標目欄(8\zw)の右余白を1ptに詰め、原本写し欄(1\zw)の左右余白を2ptずつ広げている。
% 号証欄・原本写し欄はQ[c,m,...]で中央揃え＋縦中央揃えを列側に指定しているため、
% \vcenterboxのような手製の縦中央揃えマクロは不要（tabularrayが自動で処理する）。
\begin{longtblr}[
  expand = \shokorow,  % \shokorowマクロ内の&を展開してから表を組む（tabularrayの仕様）
]{
  colspec = {|Q[c,m,wd=\dimexpr3\zw+5pt\relax]|Q[l,m,wd=8\zw]|Q[c,m,wd=\dimexpr1\zw+5pt\relax]|Q[l,m,wd=\dimexpr3\zw+20pt\relax]|Q[l,m,wd=\dimexpr4\zw+1pt\relax]|Q[l,m,wd=9.5\zw]|Q[l,m,wd=\dimexpr3\zw-4pt\relax]|},
  hlines, vlines,
  rowhead = 1,      % 先頭１行（見出し行）を全ページで繰り返す
  rowsep = 0pt,     % 行の上下余白。現行版(array版, \arraystretch=0.9)に合わせて調整済み
  row{1} = {abovesep=4pt, belowsep=4pt}, % 見出し行の上下余白
  column{1} = {leftsep=0pt, rightsep=0pt},
  column{2} = {rightsep=1pt},
  column{3} = {leftsep=1pt, rightsep=1pt},
  column{7} = {leftsep=0pt, rightsep=0pt},
}
  % 見出し行の各セルにも \SetCell{c,m} を明示すること（\shokorowの#1・#3と同じ理由）。
  % 複数行にする見出しは\shortstackではなく{ }で囲んだ素の\\を使うこと（理由は上記コメント参照）。
  \SetCell{c,m}号 証 & \SetCell[c=2]{c,m}{標　　　目\\（原本と写しの別）} & & \SetCell{c,m}{作　成\\年月日} & \SetCell{c,m}作成者 & \SetCell{c,m}立証趣旨 & \SetCell{c,m}備 考 \\

  % ==========================================================
  % ここから証拠行。
  % 「\shokorow{...}{...}{...}{...}{...}{...}{...}」１つが証拠１件（１行）分の単位です。
  %   ・行を増やす → このセットをまるごとコピーして下に貼り付ける
  %   ・行を減らす → このセットをまるごと削除する
  % セットの外側で & や \\ を直接書き足さないこと（列崩れの原因になります）。
  % hlines指定により行間の罫線は自動描画されるため、\hlineを書く必要はありません。
  % ==========================================================
  \shokorow
    {甲１}
    {【書証等の標目（例：陳述書、写真、契約書等）】\\【必要に応じ撮影日時・作成日・撮影者等を追記】}
    {原本}
    {R8.月.日}
    {【作成者】}
    {【立証趣旨】}
    {【備考】}
  % 号証番号や原本/写し欄を複数行にする場合の例（コメントアウト。必要なら使う）：
  %   {甲２\\の\\１・２}                              … 号証欄を3行に
  %   {\rotatebox{-90}{（}写し\\[-15pt]\rotatebox{-90}{）}} … 原本/写し欄を縦書き風に
  %     （\\[-15pt]は回転させた閉じ括弧の直前だけ行間を詰める調整。詰め量は
  %      \rotatebox{-90}{（}や本文の文字数によって変わるので、実際に組んで
  %      目視で調整すること。\\と[-15pt]の間に空白・改行を入れないこと（入れると
  %      \\のオプション引数として認識されず、"[-15pt]"という文字列がそのまま
  %      印字されてしまう））
\end{longtblr}
\endgroup
